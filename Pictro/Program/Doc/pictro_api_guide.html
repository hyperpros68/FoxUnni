🔍 Detect (OCR 탐색 모드)

PaddleOCR 고속 DBNet 엔진으로 배너 내 모든 텍스트 영역, 시술명, 가격, 사각 바운딩 박스 좌표를 밀리초 단위로 초정밀 추출합니다.

✨ Clear (배경 복원 모드)

텍스트 영역을 마스킹한 후 AI Big-LaMa 인페인팅 엔진을 구동하여 글자의 흔적이나 잔상을 100% 제거하고 깨끗한 원본 배경만 복원합니다.

평균 소요 시간 약 4.0초
주요 산출물 글자 제거 순수 배경 WebP/JPG
MODE: trans (기본값)

🌐 Translate (풀코스 치환)

검출 ➔ AI 뉴럴 번역(Qwen2.5) ➔ AI 배경 복원 ➔ 원본 글자색/장평 1:1 폰트 렌더링까지 전 과정을 원스톱으로 처리합니다.

평균 소요 시간 약 5.8 ~ 6.3초
주요 산출물 다국어 치환 완성본 + 배경 + 메타데이터

지원 다국어 언어 코드 (`target_lang`)

코드 대상 언어 통화 기호 렌더링 특화 처리
en (기본값) 영어 (English) USD ($) 영문 장평(Horizontal Scale) 90~95% 자동 압축으로 줄바꿈 방지
ja 일본어 (Japanese) JPY (¥) 일본 미용성형 용어 사전 매핑 & 가나/한자 굵기 보정
zh-CN 중국어 간체 (Simplified) CNY (¥) 중국 현지화 간체자 타이포그래피 적용
zh-TW 중국어 번체 (Traditional) TWD (NT$) 대만/홍콩 번체자 및 미용 용어 적용
vi 베트남어 (Vietnamese) VND (₫) 성조 부호 결합 깨짐 방지 폰트 렌더러 적용
th 태국어 (Thai) THB (฿) 상/하 모음 3단 결합 처리

상용 REST API 엔드포인트 명세

POST /api/v1/pictro/process
원스톱 다국어 배너 변환 종합 파이프라인

로컬 파일 직접 업로드 또는 원격 웹 이미지 URL을 전송하여 탐색(detect), 배경 복원(clear), 다국어 치환(trans)을 일괄 수행합니다.

파라미터 타입 필수 기본값 설명
file Multipart File 선택* None 업로드할 배너 이미지 파일 (JPG, PNG, WebP)
image_url String 선택* None 분석할 원격 웹 이미지 URL (*file과 둘 중 하나 필수)
mode String 선택 trans 동작 모드: detect | clear | trans
target_lang String 선택 en 목표 언어 코드: en, ja, zh-CN, vi, th
cURL 호출 예제 (풀코스 일본어 치환) 
curl -X POST "http://thrillrig.com:9990/pictro-api/api/v1/pictro/process" \
  -H "X-API-Key: FOXUNNI-PARTNER-MASTER-KEY-2026" \
  -F "file=@banner_sample.jpg" \
  -F "mode=trans" \
  -F "target_lang=ja"

POST /api/v1/ocr/analyze
배너 OCR 텍스트·시술명 정밀 분석 (JSON)

배너 내 문구, 시술명, 가격, 사각 바운딩 박스([ymin, xmin, ymax, xmax]) 및 인식 신뢰도를 JSON으로 반환합니다.

Python 호출 예제 
import requests

url = "http://thrillrig.com:9990/pictro-api/api/v1/ocr/analyze"
headers = {"X-API-Key": "FOXUNNI-PARTNER-MASTER-KEY-2026"}
files = {"file": open("my_banner.jpg", "rb")}

res = requests.post(url, headers=headers, files=files)
data = res.json()
print(f"검출 개수: {data['detected_count']}개, 소요시간: {data['processing_time_ms']}ms")
