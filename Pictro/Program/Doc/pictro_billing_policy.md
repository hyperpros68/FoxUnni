## 1. 3단계 상용 구독 플랜 (Plan Tiers)

픽트로는 병의원 규모와 에이전시의 배너 처리량에 맞춘 **3단계 정기 구독 모델**을 제공합니다.  
모든 플랜에는 **WebP 60% 자동 압축 엔진**이 기본 적용되어 동일 스토리지 용량 대비 **3배 이상의 배너 사진**을 보관할 수 있습니다.

| 항목 | 1단계: 베이직 (Starter) | 2단계: 프로 (Business) | 3단계: 엔터프라이즈 (Enterprise) |
| :--- | :---: | :---: | :---: |
| **플랜 코드 (`plan_id`)** | `BASIC` | `PRO` | `ENTERPRISE` |
| **타겟 고객** | 소형 피부/성형 의원, 개인 디자이너 | 전문 병원, 마케팅 대행사 | 대형 프랜차이즈 병원, 플랫폼 에이전시 |
| **월 정기 구독료 (VAT포함)** | **월 19,000원** | **월 59,000원** | **월 190,000원** |
| **기본 스토리지 보관 용량** | **10 GB** (약 15,000장 보관) | **50 GB** (약 75,000장 보관) | **100 GB** (약 150,000장 보관) |
| **월 기본 포함 변환 트래픽** | **50 GB** (약 25,000회 변환) | **300 GB** (약 150,000회 변환) | **1,000 GB (1TB)** (약 500,000회 변환) |
| **초과 변환용량 종량 단가** | **100원 / 1GB** | **80원 / 1GB** | **50원 / 1GB** |
| **단건 최대 허용 파일 크기** | 50 MB / 장 | 100 MB / 장 | 200 MB / 장 |
| **일일 최대 API 호출 쿼터** | 500 회 / 일 | 3,000 회 / 일 | 10,000 회 / 일 (초과 협의 가능) |
| **분당 속도 제한 (Rate Limit)** | 60 RPM | 300 RPM | 600 RPM |
| **구독 만료/미납 시 데이터 유예** | **30일간 보호 보관** (Grace Period) | **30일간 보호 보관** (Grace Period) | **60일간 보호 보관** (Grace Period) |

## 2. B2B 변환 용량 및 해상도 복합 미터링 과금 체계 (Hybrid Metering)

단순 호출 횟수(Request Count)만을 기준으로 과금할 경우, 4K 초고해상도 배너나 수십 MB에 달하는 대용량 배너 처리 시 발생하는 고성능 AI 연산 부하 및 네트워크 대역폭(트래픽)을 합리적으로 반영하기 어렵습니다.  
따라서 픽트로는 **"I/O 데이터 트래픽 + 메가픽셀 연산 가중치"**를 결합한 공정 복합 미터링 체계를 채택합니다.

### 2.1 복합 미터링 3대 핵심 지표
1. **입력 트래픽 (Input Bytes)**: 고객사가 API로 전송한 원본 이미지 파일의 바이트 수
2. **출력 트래픽 (Output Bytes)**: 시각화 박스 이미지, 글자 제거 배경(WebP), 번역 합성 완료 이미지 등 고객사로 전송된 총 바이트 수
3. **총 I/O 트래픽 (Total Traffic Bytes)**: `Input Bytes + Output Bytes` (DB `api_usage_log.total_traffic_bytes`에 실시간 적재)

### 2.2 메가픽셀(해상도) 연산 가중치 계수
| 해상도 티어 | 픽셀 범위 | 화소 기준 | 연산 가중치 계수 | 비고 |
| :--- | :---: | :---: | :---: | :--- |
| **Standard (표준)** | 200만 화소 이하 | FHD (1920x1080) 이하 | **1.0x (기본)** | 일반 모바일/웹 배너 |
| **High-Res (고해상도)** | 200만 ~ 850만 화소 | QHD ~ 4K UHD | **1.5x** | 원외 인쇄물, 대형 옥외 배너 |
| **Ultra-Res (초고해상도)** | 850만 화소 초과 | 4K 초과 원본 그래픽 | **2.5x** | 초대형 옥외 전광판, 무손실 원본 |

### 2.3 초과 종량 과금 산정 방식
* 당월 누적 I/O 트래픽이 플랜의 `monthly_included_volume_bytes`를 초과할 경우:
$$\text{초과 과금액 (KRW)} = \left\lceil \frac{\text{당월 사용 트래픽} - \text{기본 제공 트래픽}}{1024^3} \right\rceil \times \text{초과 단가(GB당 50~100원)}$$
* 예산 초과 방지용 **하드 리밋(`hard_limit_bytes`)**을 사전에 설정할 수 있으며, 설정된 한도 도달 시 `429 Quota Exceeded`를 반환하여 의도치 않은 추가 과금을 원천 차단합니다.

## 3. 스토리지 보관 및 유예 정책 (Grace Period)

### 3.1 영구 보관 (Active State)
* 정기 구독이 유지되는 동안에는 플랜 저장 용량(10GB / 50GB / 100GB) 내에서 **날짜 제한 없이 무기한 영구 보관**됩니다.
* 마우스 드래그&드롭 또는 모바일 앱을 통해 언제든지 원본, 배경 복원본, 다국어 치환본을 열람하거나 엑셀(XLSX)로 일괄 다운로드할 수 있습니다.

### 3.2 30일 보호 유예 기간 (Grace Period)
* **결제 실패, 카드 한도 초과 또는 구독 해지 시**:
  1. 데이터를 즉시 삭제하지 않고 **30일간의 '보호 유예 기간'**을 부여합니다.
  2. 유예 기간 동안 웹 포털 또는 API 조회 시 잔여 유예 일수가 표시되며, 이 기간 내에 재구독 또는 카드 결제 정보를 갱신하면 모든 데이터가 그대로 유지됩니다.
  3. 유예 기간(30일)이 경과할 때까지 재구독이 발생하지 않을 경우, 서버 스토리지 및 DB에서 안전하게 영구 삭제(Purge)됩니다.

### 3.3 휴지통 원클릭 복구 (Soft Delete)
* 사용자가 실수로 삭제한 배너 사진은 즉시 삭제되지 않고 **휴지통(`is_deleted = 1`)**으로 이동합니다.
* 삭제일로부터 **30일 이내**에는 언제든지 원클릭으로 원래 폴더 위치로 완벽 복구할 수 있습니다.

## 4. 정산 주기 및 영수증 증빙 (Billing & Audit Ledger)

1. **정기 결제일**: 최초 구독일(예: 매월 15일)을 기준으로 매월 동일 일자에 자동 결제(빌링키) 승인이 진행됩니다.
2. **합산 청구**: `당월 기본 플랜 구독료 + 전월 초과 변환 트래픽 종량 과금액`이 합산되어 신용카드로 결제됩니다.
3. **복식부기 감사 원장 (`client_credit_ledger`)**:
   - 모든 결제 승인, 트래픽 소진, 크레딧 충전 내역이 위변조가 불가능한 복식부기 형태로 기록됩니다.
   - 포털에서 월별 상세 이용 정산 명세서(PDF/Excel) 및 신용카드 매출전표 영수증을 즉시 다운로드할 수 있습니다.
